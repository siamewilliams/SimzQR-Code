# SimzQR Code

**A Professional QR Code Generator Built with Python and PySide6**

SimzQR Code is a modern desktop application that allows users to generate customised QR codes quickly and easily. It provides a clean graphical interface with real-time previews, custom colours, logo integration, and multiple export options.

## Features

- Real-time QR code generation and preview.
- Custom foreground and background colours.
- Light and dark themes.
- Adjustable QR code size and border.
- Four error correction levels.
- Custom centre logo integration.
- Export QR codes as PNG images.
- Export QR codes as SVG files.
- Copy generated QR codes to the clipboard.
- Persistent theme preferences.

## Technologies Used

- Python
- PySide6
- qrcode
- Pillow

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/SimzQR-Code.git
```

Navigate into the project:

```bash
cd SimzQR-Code
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python simzqr_code.py
```
